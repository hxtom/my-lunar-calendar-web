# My Lunar Calendar Website

Static website for the My Lunar Calendar iPhone/iPad app.

## Pages
- `index.html` — Marketing page
- `support.html` — Support / FAQ page
- `privacy.html` — Privacy Policy
- `styles.css` — Responsive styling

## Publish with GitHub Pages
Upload these files to the root of the `my-lunar-calendar-web` repository. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

After deployment, typical URLs will be:
- Marketing: `https://hxtom.github.io/my-lunar-calendar-web/`
- Support: `https://hxtom.github.io/my-lunar-calendar-web/support.html`
- Privacy: `https://hxtom.github.io/my-lunar-calendar-web/privacy.html`

Before App Store submission, verify that the Privacy Policy matches the actual app's data collection, SDKs, permissions, analytics, and network behavior.
